# Bike Share API

API REST en Laravel para categorías, usuarios, bicicletas, alquileres, devoluciones y reportes. El contrato está en docs/openapi.yaml.

## Desarrollo

Copie .env.example como .env, configure PostgreSQL y ejecute composer install, php artisan key:generate, php artisan migrate --seed y php artisan serve. Para las pruebas ejecute php artisan test.
